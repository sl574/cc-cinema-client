# cc-cinema-client (public mirror)

Плееры кинотеатра CC-Cinema для Minecraft (CC:Tweaked). Только код,
фильмы лежат в приватном репозитории.

```lua
wget https://raw.githubusercontent.com/sl574/cc-cinema-client/main/svideo.lua svideo.lua
wget https://raw.githubusercontent.com/sl574/cc-cinema-client/main/skino.lua skino.lua
```

Дальше нужен read-only токен приватного репозитория с фильмами:

```lua
svideo setup <token>
skino
```
